# Jarvis Soundboard Hotkeys — клиент

Глобальные хоткеи компа проигрывают звуки саундборда в твоём Discord-войсе.
Работает из любой программы (в т.ч. поверх игр) — клиент ловит клавиши и шлёт
сигнал боту через Discord.

## Установка (Windows)

1. Установи Python 3.10+.
2. В этой папке: `pip install -r requirements.txt`.
3. В Discord на сервере с ботом: `/hotkey setup` (ответ виден только тебе).
4. Скопируй `config.example.yaml` → `config.yaml`, вставь `token` и
   `webhook_url` из ответа бота.
5. Пропиши биндинги (см. ниже), запусти: `python client.py`.

## Формат биндингов

```yaml
bindings:
  "<f13>": "жыр"
  "<ctrl>+<alt>+1": "лол"
  "<ctrl>+<shift>+f14": "сос"
```

- Модификаторы: `<ctrl>`, `<alt>`, `<shift>`, `<cmd>`.
- Обычные клавиши: буква/цифра как есть, спец — в угловых скобках (`<f13>`,
  `<space>`, `<enter>`). Полный список имён — в доках pynput
  (`pynput.keyboard.Key`).
- Имя звука = как в `/sound list` (lowercase, без пробелов).
- Совет: вешай на `<f13>`–`<f24>` — их нет на обычной клавиатуре, не конфликтуют
  с играми (назначаются доп. кнопками мыши/AutoHotkey).

## Ограничения

- Эксклюзивный полноэкранный режим и некоторые античиты могут глушить
  глобальный перехват клавиш.
- Звук играет, только если ты сейчас в голосовом канале вместе с ботом.
- Задержка ~0.2–0.4с (сигнал идёт через Discord).
- Токен личный. Утёк — `/hotkey revoke`, потом снова `/hotkey setup`.
