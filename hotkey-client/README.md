# Jarvis Soundboard Hotkeys — клиент

Глобальные хоткеи компа проигрывают звуки саундборда в твоём Discord-войсе —
работает из любой программы, в т.ч. поверх игр.

## Для пользователей (Windows)

1. В Discord на сервере с ботом: `/hotkey setup` (ответ виден только тебе) —
   получишь ссылку на скачивание и персональный setup-код (действует до следующего `/hotkey setup`).
2. Скачай exe:
   `https://github.com/Spedymax/jarvis_discord/releases/download/hotkey-client-latest/jarvis-hotkeys.exe`
3. Запусти. SmartScreen ругнётся на неподписанный файл —
   «Подробнее → Выполнить в любом случае» (один раз).
4. В открывшемся окне визарда: вставь setup-код → «Нажми комбинацию» → выбери звук →
   «Добавить» → «Сохранить и запустить».
5. Клиент работает в консольном окне; закрыл окно — хоткеи перестали работать.
   Перенастройка: `jarvis-hotkeys.exe --setup`.
   Новые звуки в выпадашке — перегенерь код через `/hotkey setup`
   (токен при этом ротируется, старый перестаёт работать).
   Сбросить доступ полностью: `/hotkey revoke`.

## Для разработки

```bash
pip install -r requirements.txt
python client.py
```

Ручной `config.yaml` по образцу `config.example.yaml` по-прежнему работает —
формат не менялся. При отсутствующем или невалидном `config.yaml` клиент
автоматически открывает визард; принудительно: `python client.py --setup`.

Сборка exe локально:

```bash
pyinstaller --onefile --collect-all customtkinter --collect-all pynput --name jarvis-hotkeys client.py
```

## Как это работает

При нажатии хоткея клиент отправляет POST на Discord-вебхук, передавая токен
и имя звука в поле `username`. Бот слушает скрытый служебный канал `jarvis-hotkeys`,
проверяет токен и проигрывает нужный звук в войсе пользователя.

## Ограничения

- Эксклюзивный полноэкранный режим и некоторые античиты могут глушить
  глобальный перехват клавиш.
- Звук играет, только если ты сейчас в голосовом канале вместе с ботом.
- Задержка ~0.2–0.4с (сигнал идёт через Discord).
- Токен личный — не делись setup-кодом.
